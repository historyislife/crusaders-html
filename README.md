# Crusaders: Thy Will Be Done -- Unofficial Browser Game

『Crusaders: Thy Will Be Done』を参考に制作した、個人制作の非公式ブラウザゲームです。

ブラウザ上でプレイヤー対BOTのゲームを遊べるようにすることを目的として制作しています。

## 概要

本作では、アクションホイールを利用して各種アクションを実行し、騎士団を操作して勝利点を競います。

主な要素：

* アクションホイールによるアクション選択
* 移動・建設・招集・影響・十字軍
* ウェッジ強化
* 複数の騎士団と固有能力
* BOT対戦
* BOT vs BOT 自動テスト機能
* PC・スマートフォン・タブレット対応を想定したUI

現在も調整・デバッグを継続しています。

## 遊び方

`index.html` をブラウザで開くことで実行できます。

GitHub
Pagesを利用している場合は、公開されたページからそのままプレイできます。

詳しい操作方法・ルールについては、ゲーム画面内の `MANUAL`
を参照してください。

## 開発状況

本作は開発中です。

ゲームバランス、BOTの判断、UI、スマートフォン・タブレットでの表示などは、今後変更される場合があります。

BOTの動作確認には自動テスト機能を使用し、複数ゲームを高速実行して進行停止やゲーム状態の不整合を検出しています。
